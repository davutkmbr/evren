# Geographic data licence

The files in this folder encode geographic facts about Istanbul as plain numbers.

- **Coastlines, rivers, roads, peaks and landmark positions** are derived from OpenStreetMap data,
  © OpenStreetMap contributors, and are made available under the
  [Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- **Spot heights** were looked up from NASA SRTM 1-arc-second elevation data, which is in the public domain.

Everything else in this repository is licensed under the MIT License (see the root `LICENSE`).
